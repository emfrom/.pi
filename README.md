# .pi

My personal [Pi](https://github.com/badlogic/pi-mono) configuration. Imported skill sources live in Git submodules; this repository also provides local skill-management help.

For setup, an explanation of how the repository works, or help managing skills and their sources, invoke **`/manage-pi-skills`** in Pi. On a fresh clone, include the submodules (`git clone --recurse-submodules <repo-url> ~/.pi`), then use the skill to inspect and finish setup. It can activate or deactivate individual skills or a suitable skillset, import a Git skill repository, switch a source between a fork and its upstream, and merge upstream changes into tracked forks.
